# Cafe Report

Программа читает заказы кофейни из файла `data/orders.csv` и печатает отчёт:
количество заказов, выручку, средний чек и суммы по официантам.

Внешних библиотек нет, нужен только Python 3.10 или новее.

## Запуск

Команды выполняются из корня проекта — из папки, в которой лежит код программы.

```
python -m venv .venv
python -m app.main
python -m unittest discover -s tests -v
```

На Windows вместо `python` может потребоваться `py`, а окружение активируется
командой `.\.venv\Scripts\Activate.ps1`.

## Структура проекта

```text
cafe-report/
├── app/                 пакет приложения
│   ├── __init__.py
│   ├── main.py          точка запуска
│   ├── services/        чтение заказов, расчёты и сборка отчёта
│   │   ├── __init__.py
│   │   ├── orders.py
│   │   └── report.py
│   └── utils/           вспомогательные операции со строками и деньгами
│       ├── __init__.py
│       ├── text.py
│       └── money.py
├── data/                исходные данные
│   └── orders.csv
├── docs/                описание назначения программы
│   └── about.md
├── tests/               проверки расчётов и отчёта
│   ├── test_orders.py
│   └── test_report.py
├── requirements.txt
├── .gitignore
└── README.md
```

Файлы кеша, служебный файл ОС, старая версия программы и черновик исключены.
Файл `.env` оставлен только локально и исключён из Git и сдаваемого архива.
