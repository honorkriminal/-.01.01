# Text Kit

Набор функций для обработки строк и дат, расчётов по числам и проверки данных.
Нужен Python 3.10 или новее; внешние зависимости не требуются.

## Запуск

Из папки `lesson_03/text-kit`:
```bash
python -m app.main
python -m unittest discover -s tests -v
```
На Windows при необходимости замените `python` на `py`.

## Структура

```text
text-kit/
├── app/
│   ├── __init__.py               пакет приложения
│   ├── main.py                   примеры данных и запуск
│   ├── utils/
│   │   ├── __init__.py           пакет вспомогательных функций
│   │   ├── text.py               пробелы, сокращение, инициалы, slug
│   │   └── dates.py              чтение, форматирование и сравнение дат
│   └── services/
│       ├── __init__.py           пакет правил проекта
│       ├── statistics.py         среднее, медиана, разброс, частоты
│       └── validation.py         проверка почты, телефона и пароля
├── tests/
│   ├── test_text.py              тесты строк
│   ├── test_dates.py             тесты дат
│   ├── test_statistics.py        тесты расчётов
│   └── test_validation.py        тесты проверки данных
├── .gitignore                    исключение окружения и кеша
└── README.md                     инструкция
```

## Почему четыре модуля

Функции объединены по ответственности. Общие операции со строками и датами
находятся в `utils`, расчёты и правила проверки данных — в `services`.
`validation.py` импортирует `clean_spaces` из модуля строк. Остальные
вспомогательные модули не зависят от точки запуска. Тела исходных функций
сохранены, изменены только размещение и импорты.
